# Security Policy

## Reporting a Vulnerability

Use GitHub's **private vulnerability reporting**: go to the
[Security tab](https://github.com/qfunction-ai/letta-local/security) and click
**Report a vulnerability**, or go directly to
<https://github.com/qfunction-ai/letta-local/security/advisories/new>.

Include a description of the vulnerability, steps to reproduce, and any
relevant details.

Do **not** open a public issue for security vulnerabilities.

We aim to acknowledge reports promptly.

## Supported Versions

Security fixes are applied to **0.16.38 and later**.

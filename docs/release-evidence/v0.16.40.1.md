## Interim-review fold-in (V16_41_interim_notes.md, 2026-11-26 10:30)

**T-1 — TypeScript number-branch injection (sibling of the S-1 str() fix):** `convert_param_to_ts_value` returned `str(raw_value)` for number/integer params — a model-supplied string was emitted verbatim into TypeScript code. Fixed: only real numbers or strings that PARSE as numbers are accepted; the parsed value is `json.dumps`'d. Rejected with the same named ValueError class as the Python path. Impact was lower (TS tools run only on E2B — only deployments with an E2B key), but it is the same injection.

**T-2 — `letta server --host` never reached the guard on bare metal:** the guard is constructed at app import time and read `os.getenv("HOST")`; the CLI's `--host` went to uvicorn/granian without ever entering the environment — same misclassification as the container A-1 bug (403s every LAN client). Fixed both sides: `start_server` records `os.environ["HOST"] = host` before the server starts, and the middleware re-resolves HOST once on first dispatch (a wildcard/LAN env host recomputes enforcement and the allowed-host set; the constructor default still covers the no-flag path). The JS-reserved-words note (names like `var`/`let` produce a syntax error, not an injection; schema membership bounds the names) — noted, no change.
